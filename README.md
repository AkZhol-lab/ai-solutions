# AI Solutions — Landing Page

Одностраничный коммерческий сайт: AI-агенты и автоматизация для бизнеса (Астана). Статический HTML/CSS/JS без сборки и зависимостей.

## Структура
```
index.html          страница: разметка, тексты, SEO-мета, JSON-LD
assets/style.css    дизайн и адаптивность (breakpoints 1080 / 960 / 640)
assets/main.js      меню, анимации, демо-чат, сборщик сообщения в Telegram
assets/favicon.svg  иконка
robots.txt
```

## Публикация
Сайт: https://akzhol-lab.github.io/ai-solutions/ (GitHub Pages, ветка `main`, корень репозитория).
Обновление: изменить файлы → `git add -A` → `git commit -m "..."` → `git push`. Через 1–2 минуты изменения появятся на сайте.

## Запуск локально
```powershell
# в папке проекта
python -m http.server 5173 --bind 127.0.0.1
# открыть http://127.0.0.1:5173/
```
Можно и просто открыть `index.html` двойным щелчком: страница работает без сервера.

## Контакты
Все CTA ведут на `https://t.me/zholic_01` (аккаунт проверен 2026-11-18). Кнопки в шапке и на первом экране открывают чат с готовым первым сообщением «Здравствуйте! Хочу обсудить задачу для своего бизнеса.» (параметр `?text=` по документации Telegram). Ник задан в двух местах: ссылки в `index.html` и константа `TG_USER` в `assets/main.js`.

Форма «С чем связана задача?» ничего не отправляет на сервер. Она собирает текст и открывает чат Telegram с подставленным сообщением (`?text=`), а также копирует текст в буфер на случай, если клиент Telegram его не подставит.

## SEO и превью ссылок
`canonical`, `og:url`, `og:image` (`assets/og.png`, 1200×630), `sitemap.xml` и `robots.txt` настроены на адрес GitHub Pages. При переходе на собственный домен заменить адрес `https://akzhol-lab.github.io/ai-solutions/` во всех четырёх местах (`index.html`, `sitemap.xml`, `robots.txt`).

Формулировки кейсов и статусов (раздел «Наши разработки») взяты из документов проектов на 2026-11-18.
